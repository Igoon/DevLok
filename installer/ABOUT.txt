DevLok
Local development environment manager

DevLok menyiapkan, menjalankan, dan mengelola lingkungan pengembangan web
lokal (Nginx, PHP, MySQL, dan tool pendukung) dalam satu aplikasi GUI dan CLI
untuk Windows dan macOS.

Kemampuan utama:
 - Menjalankan banyak project PHP dengan versi runtime berbeda
 - Domain lokal *.test otomatis tanpa mengedit hosts manual
 - HTTPS lokal dengan certificate yang dipercaya sistem
 - Database MySQL otomatis untuk setiap project
 - Menjalankan/menghentikan service dari GUI, tray, atau CLI
 - Import project dan virtual host dari Laragon
